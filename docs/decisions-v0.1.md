# KATANA-UCHI v0.1 — 임시 결정 기록

작성: 2026-10-01 · 기준 문서: `docs/KATANA-UCHI_GDD_v0.1_Final.md`

이 문서는 GDD의 **[v0.1 제안]·[미결]** 부분을 실제로 돌리기 위해 정한 임시 규칙과 그 이유를 적는다.
여기 적힌 수치와 규칙은 **본편 확정 설정이 아니다.** 플레이해 본 뒤 고치는 것을 전제로 한다.
수치는 대부분 `data/*.json`에 있어 코드 수정 없이 바꿀 수 있다.

## 2. 탐험 (확정 규칙을 지키는 방식)

확정 규칙: 직접 이동 없음 · 인접 노드 한 구간만 선택 · 하루 단위 자동 이동 · 매일 사건(아무 일 없음 포함) · 진행/노숙/되돌아가기 선택 · 전체 루트 자동 예약 없음. 아래는 그 위에 얹은 임시 결정이다.

### 2.1 지도
- 노드 5개: **공방 마을(거점)**, 숯가마 숲, 갈림길 주막, 강변 사철터, 철광 산지.
- 길 6개, 1~3일. 갈림길(주막)과 순환(숲–강변–산지)이 있어 같은 목적지에 여러 경로가 있다.
- 지도에서 인접 노드만 빛나는 테두리로 표시한다. 비인접 노드를 누르면 "직접 연결된 장소만 목적지로 고를 수 있습니다"를 보여 주고 아무 것도 진행하지 않는다.
- 출발 전 패널에 **편도·왕복 식량 예상치와 피로 증가 예상**, 식량 부족·탈진 경고를 보여 준다 (GDD 4.2 "출발 전에 왕복 거리와 보급 상태를 확인").

### 2.2 하루의 순서
1. 행동(출발·진행·되돌아가기·노숙)을 누르면 **하루가 지나고** 그날의 소비가 적용된다.
2. 그날의 사건이 **정확히 1번** 뽑힌다. 사건 대응 전에는 다음 행동 버튼이 잠긴다.
3. 사건 대응은 **하루를 더 쓰지 않는다** (GDD 3.3).
4. 행동 선택 화면에서 기다리는 동안 날짜·거리는 움직이지 않는다.

### 2.3 위치·방향
- 구간 길이 D(정수 일), 출발점으로부터 위치 x. 하루 이동량 1.
- **출발 = 첫날 이동**을 바로 처리한다 (GDD 3.3).
- **되돌아가기**는 그 자리에서 출발점 방향으로 **하루 이동을 실제로 수행**한다. 순간 귀환 없음.
- 귀환 중 버튼은 **귀환 계속 / 노숙하기 / 목적지로 다시 향하기**. *(GDD 11장 미결 "귀환 중 재전진 허용" → v0.1은 허용.)*
- x는 0과 D 사이로 묶이며 노드 경계를 넘지 않는다.

### 2.4 도착일 *(GDD 11장 미결 "도착일 이벤트 순서")*
- 끝점에 닿은 날에도 그날의 **길 위 사건은 1번** 일어난다(하루 이동마다 사건 1회 규칙 유지).
- 사건을 해결하면 길 위 행동 대신 **"○○에 들어가기"**만 나온다.
- 장소에 들어갈 때 사건을 따로 굴리지 않는다 → 도착일 사건이 중복되지 않는다.
- 출발점으로 되돌아온 경우도 같은 방식으로 출발지에 들어간다.

### 2.5 노숙 *(GDD 11장 미결 "노숙의 정식 시간 모델")*
- 이동 없이 **하루 소비**, 식량 −1, 피로 −4. 위치 유지.
- 그날 야영 사건이 1번 일어난다 (조용한 야영이 가장 흔함, 별밤 / 밤비 / 늑대 울음).

### 2.6 생존 자원 *(GDD 11장 미결 "식량·피로 등 생존 요소의 최종 채택")*
GDD 4.2 제안대로 **식량과 피로** 두 개만 쓴다.

| 값 | 결정 |
|---|---|
| 식량 | 시작 6, 최대 10. 이동·노숙·채집하는 날 −1 |
| 피로 | 0~10. 이동 +2, 채집 +1, 노숙 −4. 7 이상이면 "지침" |
| 굶주림 | 식량이 모자란 날은 식량 0, 피로 +3 |
| 지침 효과 | 지친 채 채집한 원료는 불순도 +6 (결과에 이어지도록) |

### 2.7 임시 실패 처리 *(GDD 11장 미결 "탐험 실패 비용")*
- 사건까지 해결한 뒤 피로가 10이면 **탈진**.
- "정신을 차린다" → 손실 내역 표시: **원료 절반(올림) 잃음, 남은 식량 모두 잃음, 2일 경과**.
- 공방 마을에서 식량 3, 피로 5로 다시 시작한다. 마을 보급은 무료라 플레이가 막히지 않는다.

### 2.8 장소 활동
| 장소 | 활동 | 비용·효과 |
|---|---|---|
| 공방 마을 | 공방에 들어가기 / 보급(식량 최대) / 묵으며 쉬기 | 보급 무료, 쉬기 1일·피로 0 |
| 갈림길 주막 | 주먹밥 얻기(식량 6까지, 방문당 1회) / 쉬기 / 소문 듣기 | 소문 = 제작 힌트 문장 |
| 숯가마 숲 | 숯 확보 (좋은 숯 +2) / 근처 야영 | 1일, 식량 −1, 피로 +1, 방문당 2회 |
| 강변 사철터 | 사철 일기 (사철 원료 +1) / 근처 야영 | 〃 |
| 철광 산지 | 철광석 캐기 (철광석 원료 +1) / 근처 야영 | 〃 |

- 장소 활동에는 사건을 붙이지 않았다(사건은 길 위에서만).
- 방문 횟수 제한은 "한 번 가서 무한 채집"을 막는 임시 장치다. 다시 들어오면 초기화된다.
- 숲–강변 순환으로만 다니면 식량이 빠듯하고, 주막을 거치면 쉬고 보급할 수 있다. 경로 선택이 의미를 갖도록 의도한 배치다.

### 2.9 사건 묶음 (`data/events.json`)
- 이동한 날 9종: 아무 일 없음(지형별 문구), 버려진 숯 자루, 검게 반짝이는 모래(길가 사철), 행인(정보), 떠돌이 상인(교환), 갑작스러운 비, 무너진 산길, 산적, **다리 위의 거구(벤케이 첫 만남, 고유)**.
- 노숙한 날 4종: 조용한 야영, 별이 많은 밤, 밤비, 늑대 울음.
- 지형별 후보에서 가중 추첨. 선택지마다 필요 조건(식량·숯·동행자)을 표시하고, 조건이 안 되면 비활성으로 이유를 보여 준다. 결과 문구 아래에 변화(식량·피로·아이템)를 표시한다.
- 고유 사건은 `GameState.flags`에 완료를 기록해 다시 나오지 않는다 (GDD 4.1).

### 2.10 동행자
- **벤케이 한 명만** 구현. "나는 도공이오"를 고르면 동행한다(칼을 보여 주기로 한 약속).
- 효과는 GDD 5장 제안 범위: 산적 사건에서 손실 없이 해결, 늑대 울음에서 불침번. 이동 화면에 함께 걷는 모습으로 표시.
- 호감도·성장·서사는 넣지 않았다.

## 3. 공방

흐름: **① 재료 감정·선택 → ② 단련(강재 2개) → ③ 피철·심철 배정 → ④ 접합(자동) → ⑤ 성형 → ⑥ 다듬기·점토(기본 패턴) → ⑦ 담금질 → 결과.** 상단 띠에 현재 공정을 표시한다.

### 3.1 재료와 제철
- 원료 프리셋 (`data/materials.json`)

| 원료 | 탄소 % | 균일도 | 불순도 | 성격 |
|---|---|---|---|---|
| 강변 사철 | 0.62~0.92 | 36~50 | 14~24 | 날(피철)용 |
| 산 철광석 | 0.14~0.34 | 26~40 | 34~48 | 속심(심철)용 |
| 길가 사철 (사건) | 0.45~0.75 | 24~38 | 24~36 | 들쭉날쭉 |
| 창고 고철 (대비용) | 0.30~0.50 | 18~28 | 44~56 | 막히지 않게 하는 최후 수단 |

- 원료 값은 **채집 순간** 범위 안에서 정한다. 공방에서 **제철 = 원료 1 + 숯 1 → 강괴**. 좋은 숯(숯가마 숲)이 있으면 먼저 쓰고, 탄소 +0.05, 불순도 −5.
- 원료·강괴에 **출처(장소·일차)**를 남기고 결과 화면까지 이어 보여 준다 (GDD 6장).
- 감정 표시: 일반 화면은 낮음/보통/높음, F12를 누르면 실제 수치.
  - 탄소: <0.45 낮음, <0.65 보통, <0.9 높음, 그 이상 매우 높음
  - 균일도: <40 낮음, <65 보통, 그 이상 높음 / 불순도: <20 낮음, <38 보통, 그 이상 높음
- 강괴+제철 가능한 원료가 2개 미만이면 **창고의 고철 강괴 받기** 버튼이 나온다 → 재시도가 영구히 막히지 않는다.
- 단련을 시작하면 고른 강괴 2개는 소모된다. v0.1에서는 시작한 제작을 중간에 그만둘 수 없다.

### 3.2 가열·접쇠 (단련)
GDD 7.2 제안대로 공방 안에서만 흐르는 짧은 실시간 구간. 버튼: 숯 보충 / 풀무질 / 꺼내서 모루에 올리기 / 화덕에 다시 넣기 / 산화물 털기 / 늘이고 접기 / 단련 마치기.

- 화덕 온도 = 300 + 숯×8 + 풀무×4.5 (숯 0~100은 초당 2.5 줄고, 풀무 바람은 초당 22 줄어듦). 강재 온도는 화덕을 천천히 따라간다.
- **침탄**: 900~1200°C, 숯 40 이상일 때 초당 +0.005%. 숯 보충 즉시 탄소가 오르지 않는다 (GDD 7.2).
- **과열** (>1250°C): 탈탄(초당 −0.03%), 산화물이 빠르게 쌓임. **백열** (>1350°C): 불순도↑, 균일도↓.
- **접기 1회**: 균일도 +(100−U)×0.30×효율, 불순도 −I×0.20×효율, 탄소 −0.035%(1200°C 넘으면 −0.055%), 온도 −120°C.
  - 효율 = 0.85^(이미 접은 횟수) × (1 − 남은 산화물×0.7) → 반복할수록 개선 폭이 줄고, 산화물을 털지 않으면 효과가 떨어지고 산화물이 불순물로 접혀 들어간다.
  - 850°C 아래에서 접으면 효과 ×0.6, 불순도 +1.5. 750°C 아래에서는 접을 수 없다. 최대 10회.
- 화덕용 숯은 **추상화**해 인벤토리 숯을 쓰지 않는다. 인벤토리 숯은 제철에만 쓴다. (이유: 가열 중 숯이 떨어져 제작이 막히는 일을 피하려고. 숯의 경제는 다음 버전 검토.)
- 온도는 항상 **색 + 문구**(검은빛 / 어두운 적색 / 짙은 진홍 / 밝은 진홍 / 주홍 / 주황 / 노란 주황 / 노란빛(과열) / 백열)로 보여 준다 (GDD 10장).

### 3.3 배정·접합
- 단련을 마친 뒤 두 강재를 나란히 보여 주고, 어느 쪽을 **피철(날·바깥층)**로 쓸지 고른다. 나머지가 **심철(속심)**.
- 두 강재의 세 변수는 **평균내지 않고 따로 유지**한다 (GDD 7.3).
- 츠쿠리코미는 피철이 심철을 감싸는 **고정 구조 하나로 자동 처리** (짧은 망치 연출만).

### 3.4 성형
- 도신을 **6구간**(칼끝~밑동)으로 나누고 구간 버튼으로 두드린다. 구간별 진행 막대와 공통 온도를 표시.
- 온도 800°C 이상 +15, 650~800°C +8, 650°C 미만 +4이며 **냉간 타격**으로 기록. 120을 넘기면 **과타격**(얇아짐).
- 초당 28°C씩 식는다. "다시 달구기"는 1.2초 연출 뒤 1050°C.
- 모든 구간이 60 이상이면 마칠 수 있다. 형상 품질 = 구간 평균(100 상한) − 과타격×3. 구간 편차도 기록한다.
- 성형 이후 강재 세 변수는 바뀌지 않는다. 형상 품질·결함만 따로 기록 (GDD 7.3).
- 고정 목표 형상 한 가지. 길이·무게·곡률 설계는 없음.

### 3.5 다듬기·점토 *(GDD 7.4 미결 "점토 도포 방식")*
- **기본 패턴 하나**(등 쪽 두껍게, 날 쪽 얇게)를 버튼 하나로 바른다. 계산에 영향을 주는 선택지는 아직 없다.

### 3.6 담금질
- 화덕에서 350°C부터 950°C를 향해 서서히 달궈진다. "화덕에서 잠시 꺼내 식히기 / 다시 넣기"로 조절할 수 있다.
- 플레이어가 "담금질!"을 누른 순간의 온도가 결과에 쓰인다. 적정 범위 **760~840°C(밝은 진홍)**. 730°C 미만은 경화 부족, 840°C 초과는 균열 위험 증가. 가열 중 최고 온도가 900°C를 넘으면 조직이 거칠어진 것으로 본다.
- 힌트: 화면의 도공의 말, 주막 소문.

### 3.7 결과 계산 (무작위 없음)
같은 재료·같은 조작이면 항상 같은 결과다. 원인 설명은 실제 계산에 들어간 항목에서만 만든다.

- **경화**: 담금질 < 730°C 또는 피철 탄소 < 0.45 → 경화 부족 / 피철 균일도 < 55 → 국소 불균일 / 담금질 < 760°C 또는 피철 탄소 < 0.55 → 다소 약한 경화 / 그 외 충분한 경화.
- **건전성**: 위험 점수를 더한다.
  - 균열 계열: 담금질 과열 (Tq−840)×0.25, 가열 중 과열 (Tmax−900)×0.1, 피철 탄소 과다 (C−0.85)×100, 피철 불순도×0.4, 심철 불순도×0.15, 냉간 타격×8
  - 휨 계열: 심철 탄소 과다 (C−0.5)×80, 성형 편차 (σ−10)×0.8, 피철 균일도 부족 (60−U)×0.3
  - 합계 <20 정상 / 20~35 휨 또는 미세 균열(많은 쪽 계열) / 35~55 균열 / 55 이상 파단
- **형상**: 품질 ≥90이고 결함 없음 → 고른 형상 / ≥75 → 대체로 고름 / 그 아래 형상 불량. 결함 목록(덜 두드린 구간, 과타격, 냉간 타격, 두께 편차) 표시.
- **등급**: 점수 = 경화×0.4 + (100 − 위험×1.5)×0.4 + 형상×0.2. 파단 → 실패작, 균열 → 불량품, 경화 부족 → 미흡, 그 외 85↑ 명품 / 70↑ 양품 / 55↑ 보통 / 미흡.
- 결과 화면: 도신 그림(경화되면 하몬, 휨이면 더 휜 모양, 균열·파단은 금과 틈), 세 축 카드, 원인(▼ 나빴던 점 상위 4개, ▲ 좋았던 점), 사용 재료와 출처, 지난 결과 4개 비교.

### 3.8 공방의 달력 소모 *(GDD 11장 미결)*
- 제작 한 번 = **3일 고정**, 결과가 나올 때 더한다. 제철은 0일.

## 4. 결과 이후·재시도
- 결과 화면에서 **공방에서 다시 만들기**(남은 강괴·원료로) 또는 **지도로(다음 탐험)**.
- 재료가 없어도 창고 고철로 다시 만들 수 있고, 탈진해도 마을에서 다시 시작하므로 플레이가 영구히 막히지 않는다.
- 저장/불러오기는 없다. 게임을 끄면 처음부터.

## 5. 아트 방향 적용
- 지도: 땅·강·숲·산·논밭·길을 그리고, 장소마다 아이콘(마을 집, 숯가마, 주막 깃발, 사철 홈통, 갱도). 현재 위치 깃발, 인접 노드 깜빡이는 테두리, 선택 구간 점선, 굴뚝·숯가마 연기와 물결.
- 이동: 지형별 배경 4종, 걷는 도공(삿갓·등짐), 구름. 노숙 시 밤 덮개·별·모닥불·천막, 비 사건 시 빗줄기, 벤케이 동행 표시. 사건 인물은 24×24 초상(행인·상인·산적·벤케이).
- 장소: 장소별 배경 5종과 짧은 반복 효과(연기, 숯가마 불, 등불, 물결, 낙석), 활동 결과가 떠오르는 표시.
- 공방: 화덕(불꽃 높이·색이 숯·풀무를 반영), 굴뚝 연기, 모루, 물통, 강재(온도색 + 산화물 얼룩), 망치 타격, 불꽃 입자, 산화물 부스러기, 성형 중 도신, 점토, 담금질 증기.

## 6. 일부러 넣지 않은 것
자동 경로 탐색·여러 구간 예약, 캐릭터 직접 이동, 전투, 의뢰·판매·평판, 동행자 성장, 점토 패턴 선택, 칼 형상 설계, 저장, 사운드.
