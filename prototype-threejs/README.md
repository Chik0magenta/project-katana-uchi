# KATANA-UCHI v0.1 — three.js 플레이 시안

`docs/KATANA-UCHI_GDD_v0.1_Final.md`(저장소 루트)를 기준으로 three.js로 새로 만든 픽셀아트 플레이 시안이다.
이전 Godot v0.1 구현(저장소 루트의 `project.godot`, `scripts/` 등)의 코드·씬·그림은 쓰지 않았고 그 파일들도 건드리지 않았다.
이 시안을 기준으로 Godot에서 다시 구현할 예정이라 **규칙·데이터(`src/core`, `src/data`)와 그림·UI(`src/render`, `src/ui`)를 분리**했다.

플레이 흐름: **지도 → 이동 사건 → 재료 확보 → 귀환 → 공방 제작 → 결과 → 재시도**

## 실행

**가장 쉬운 방법:** `dist/katana-uchi.html`을 브라우저(Chrome·Edge·Firefox·Safari)로 연다. 파일 하나에 모든 것이 들어 있어 설치나 인터넷 연결이 필요 없다.

직접 빌드하거나 고치면서 보려면 (Node 18 이상):

```bash
cd prototype-threejs
npm install
npm run dev        # http://localhost:5173 — 파일을 고치면 다시 빌드 (새로 고침)
npm run build      # dist/katana-uchi.html 다시 만들기
npm test           # 규칙 테스트 (브라우저 없이)
npm run playtest   # 헤드리스 Chromium으로 전체 흐름 자동 플레이 + 캡처 (Playwright 필요)
```

- 조작은 마우스만으로 된다. **F2**(또는 `` ` ``)로 개발용 실제 수치를 켜고 끈다.
- 타이틀의 **개발용 메뉴**에서 지도·이동·장소·공방 각 단계·결과로 바로 들어갈 수 있다.
- 진행은 화면을 옮길 때마다 브라우저에 자동 저장되고, 타이틀에서 **이어하기**로 돌아온다.
- 주소 뒤에 `?seed=123`을 붙이면 같은 사건·재료가 나온다.
- 창 크기에 맞춰 1280×720 화면이 비율을 지키며 확대·축소된다. 그림은 320×180을 정수 4배로 그린다.

## 플레이 방법 (요약)

1. **공방 마을**에서 시작한다. 보급(식량 가득)을 하고 **지도 열기**.
2. 지도에서 **연결된 장소 하나**를 골라 출발한다. 출발 패널에 편도·왕복 일수와 식량·피로 예상이 나온다.
3. 길 위에서는 **하루마다** 사건을 해결하고 **진행하기 / 노숙하기 / 되돌아가기** 중 하나를 고른다.
   돌아가는 중에는 **귀환 계속 / 노숙하기 / 목적지로 다시 향하기**.
4. **사철 강변**(날용 사철), **철광 산지**(속심용 철광석), **숯가마 숲**(좋은 숯), **갈림길 찻집**(주먹밥·휴식·소문).
5. 마을로 돌아와 **공방**에서: 재료 두 개 고르기 → 두 강재를 각각 달구고 접기 → 피철·심철 배정 → 접합 → 구간별 성형 → 점토 → 담금질.
6. **결과**에서 경화·건전성·형상과 그렇게 된 원인을 보고 다시 만든다. 재료가 없어도 창고 고철로 다시 만들 수 있다.

## 폴더

```
prototype-threejs/
  src/
    data/        지도·사건·재료·장소·밸런스 (수치는 여기서 고친다)
    core/        규칙 (탐험·장소·공방 공정·결과). DOM·three.js를 모른다
      forge/     공방 세션과 단련·성형·담금질 시뮬레이터, 결과 계산, 발열색
    render/      three.js 픽셀 무대, 팔레트, 픽셀 드로잉, 입자, 화면별 그림
    ui/          한국어 DOM UI (화면별)
    main.js      화면 전환·상단 정보 막대·저장
    styles.css
  tests/         규칙 테스트 (node --test)
  tools/         playtest.mjs(전체 흐름 자동 플레이), shoot.mjs(개발 메뉴 화면 캡처)
  docs/
    decisions-v0.1.md   임시 규칙과 이유
    godot-port.md       Godot 재구현 대응표
    screenshots/        자동 플레이 캡처
  dist/katana-uchi.html 빌드 결과 (이 파일 하나로 실행)
```

`.gdignore`가 있어 저장소 루트의 Godot 프로젝트를 열어도 이 폴더는 가져오지 않는다.

## 사용한 외부 자산
