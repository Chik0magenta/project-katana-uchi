# KATANA-UCHI v0.1 three.js 시안 — 임시 결정 기록

작성: 2026-10-01 · 기준 문서: `docs/KATANA-UCHI_GDD_v0.1_Final.md` (저장소 루트)

이 문서는 GDD의 **[v0.1 제안]·[미결]** 부분을 실제로 돌리기 위해 이 three.js 시안에서 정한 임시 규칙과 그 이유를 적는다.
여기 적힌 수치와 규칙은 **본편 확정 설정이 아니다.** 플레이해 본 뒤 고치는 것을 전제로 한다.
수치는 대부분 `src/data/*.js`에 모여 있어 규칙 코드를 건드리지 않고 바꿀 수 있다.

> 이 시안은 이전 Godot v0.1 구현의 코드·씬·그림을 **재사용하지 않고** 새로 만들었다. 규칙도 GDD에서 다시 해석했다.
> 이후 Godot 재구현의 기준이 되도록 규칙·데이터와 그림·UI를 분리했다. 이식 방법은 [`godot-port.md`](godot-port.md).

## 1. 작업 환경과 구성

## 2. 탐험

확정 규칙은 그대로 구현했다: 직접 이동 없음 · 인접 노드 한 구간만 선택 · 하루 단위 자동 이동 · 매일 사건 1회('아무 일 없음' 포함) · 진행/노숙/되돌아가기 선택 · 전체 루트 자동 예약 없음.

### 2.1 지도 (`data/map.js`)
- 노드 5개: **공방 마을(거점)**, 갈림길 찻집, 숯가마 숲, 사철 강변, 철광 산지. 길 6개, 1~3일.
- 찻집이 세 갈래 길의 갈림길이다. 숲은 마을(2일)·찻집(1일) 양쪽에서, 산지는 찻집(3일)·강변(2일) 양쪽에서 갈 수 있어 경로 선택이 생긴다.
- 지도 위 길에 **하루 눈금**과 "N일" 표시. 인접 노드는 노란 고리가 깜빡인다.
- 비인접 노드를 누르면 "직접 연결된 장소만 목적지로 고를 수 있습니다"만 보이고 아무것도 진행하지 않는다.
- 출발 전 패널: 길 이름·지형, **편도/왕복 일수, 편도/왕복 식량, 피로 증가 예상**, 식량 부족·탈진 위험 경고 (GDD 4.2).

### 2.2 하루의 순서
1. 행동(출발·진행·되돌아가기·노숙)을 누르면 **하루가 지나고** 그날의 소비가 적용된다.
2. 그날의 사건이 **정확히 1번** 뽑힌다. 대응이 필요한 사건은 대응 전까지 다음 행동 버튼이 나오지 않는다.
3. 사건 대응은 **하루를 더 쓰지 않는다** (GDD 3.3).
4. 행동을 고르기 전에는 날짜·거리가 움직이지 않는다 (실시간 요소 없음).

### 2.3 위치·방향
- 구간 길이 D(정수 일), 출발점으로부터 위치 x, 하루 이동량 1. 진행 막대에 칸 D개와 현재 위치, 방향, 양 끝까지 남은 일수 표시.
- **출발 = 첫날 이동**까지 처리 (GDD 3.3).
- **되돌아가기**는 방향을 바꿔 그 자리에서 **하루 이동을 실제로 수행**한다. 순간 귀환 없음.
- 귀환 중 버튼은 **귀환 계속 / 노숙하기 / 목적지로 다시 향하기**. *(GDD 11장 미결 "귀환 중 재전진 허용" → 허용.)*
- x는 0~D로 묶이고 끝점에서 멈춘다 → 노드 경계를 넘지 않는다.

### 2.4 도착일 *(미결 "도착일 이벤트 순서")*
- 끝점에 닿은 날에도 그날의 길 위 사건은 1번 일어난다(하루 이동마다 사건 1회 규칙 유지).
- 사건을 해결하면 행동 버튼 대신 **"○○에 들어가기"**만 나온다. 장소에 들어갈 때 사건을 다시 굴리지 않는다 → 중복 없음.
- 출발점으로 되돌아온 경우도 같은 방식.

### 2.5 노숙 *(미결 "노숙의 정식 시간 모델")*
- 이동 없이 **하루 소비**, 식량 −1, 피로 −4, 위치 유지 (GDD 3.3 제안 그대로).
- 그날 **야영 사건**이 1번 일어난다: 조용한 야영(가장 흔함) / 별이 쏟아지는 밤(피로 추가 −1) / 밤비 / 늑대 울음.
- 화면은 밤하늘 + 모닥불 연출로 바뀐다.

### 2.6 생존 자원 *(미결 "생존 요소의 최종 채택")* — `data/balance.js`
GDD 4.2 제안대로 **식량과 피로** 두 개만.

| 값 | 결정 | 이유 |
|---|---|---|
| 식량 | 시작 8, 최대 10. 이동·노숙·채집하는 날 −1 | 마을→강변 왕복(6일)+채집 2일 = 8. 찻집 보급을 거치면 여유가 생겨 경로 선택이 의미를 갖는다. |
| 피로 | 0~10. 이동 +2, 채집 +1, 노숙 −4 | 3~4일 걸으면 노숙이나 휴식을 고민하게 된다. |
| 굶주림 | 식량이 모자란 날은 식량 0, 피로 +3 | 식량이 떨어져도 바로 실패하지 않고 피로로 압박. |
| 지침(피로 7+) | 지친 채 채집한 원료는 불순도 +6 | 탐험 상태가 제작 결과로 이어지도록. |

### 2.7 임시 실패 처리 *(미결 "탐험 실패 비용")*
- 사건까지 해결한 뒤(또는 장소 활동 뒤) 피로가 10이면 **탈진**.
- "정신을 차린다" → 손실 내역 표시: **원료 절반(올림) 잃음, 남은 식량 모두 잃음, 2일 경과** → 공방 마을에서 식량 3, 피로 4로 재개.
- 마을 보급은 무료라 플레이가 영구히 막히지 않는다.

### 2.8 장소 활동 (`data/locations.js`)
| 장소 | 활동 | 비용·효과 |
|---|---|---|
| 공방 마을 | 공방에 들어가기 / 보급(식량 최대, 무료) / 집에서 쉬기(1일, 피로 0) | |
| 갈림길 찻집 | 주먹밥 얻기(식량 +3, 방문당 1회) / 하룻밤 묵기(1일, 피로 0, 식량 소비 없음, 방문당 1회) / 소문 듣기(제작 힌트) | |
| 숯가마 숲 | 숯 굽기 돕기(1일, 좋은 숯 +2, 방문당 2회) / 근처 야영 | 1일·식량 −1·피로 +1 |
| 사철 강변 | 사철 일기(1일, 강변 사철 +1, 방문당 2회) / 근처 야영 | 〃 |
| 철광 산지 | 철광석 캐기(1일, 산 철광석 +1, 방문당 2회) / 근처 야영 | 〃 |

- 장소 활동에는 사건을 붙이지 않았다(사건은 길 위에서만) — 하루 1사건 규칙을 이동일에만 적용해 단순하게.
- 방문당 횟수 제한은 "한 번 가서 무한 채집"을 막는 임시 장치. 다시 들어오면 초기화.

### 2.9 사건 묶음 (`data/events.js`)
- 이동한 날 11종: 아무 일 없음(지형별 문구), 버려진 숯 자루, 검게 반짝이는 모래(길가 모래쇠), 산열매 덤불, 지나가는 행인(소문), 떠돌이 상인(교환), 갑작스러운 비, 무너진 길, 산적, 늑대 발자국, **다리 위의 거구(벤케이 첫 만남, 고유)**.
- 노숙한 날 4종 (2.5 참고).
- 길의 지형별 후보에서 **가중 추첨**. 같은 사건이 연달아 나오지 않게 직전 사건의 가중치를 낮춘다. 산적은 3일차부터, 벤케이는 2일차부터.
- 선택지마다 필요 조건(식량·숯·원료·동행자)을 표시하고, 조건이 안 되면 비활성 + 이유를 보여 준다. 결과 문구 아래에 변화(식량·피로·숯·원료)를 칩으로 표시.
- 고유 사건은 `flags`에 완료를 기록해 다시 나오지 않는다 (GDD 4.1).
- 사건 결과는 무작위가 아니라 고른 선택지에 따라 정해진다 — 판단이 읽히도록.

### 2.10 동행자
- **벤케이 한 명**. 첫 만남에서 "나는 도공이오…"를 고르면 동행(칼을 보여 주기로 한 약속).
- 효과는 GDD 5장 제안 범위: 산적·늑대 발자국·늑대 울음 사건에서 손실 없는 선택지가 열린다. 이동·장소 화면에 함께 그려진다.
- 호감도·성장·서사는 없음.

## 3. 공방

흐름: **① 감정·제철 → ② 단련(강재 2개) → ③ 배정 → ④ 접합(자동) → ⑤ 성형 → ⑥ 점토 → ⑦ 담금질 → ⑧ 결과.** 화면 위 띠에 현재 공정을 표시.

### 3.1 원료·감정·제철 (`data/materials.js`)
| 원료 | 탄소 % | 균일도 | 불순도 | 성격 |
|---|---|---|---|---|
| 강변 사철 | 0.62~0.90 | 38~52 | 12~22 | 날(피철)용 |
| 산 철광석 | 0.14~0.32 | 28~42 | 30~44 | 속심(심철)용 |
| 길가 모래쇠 (사건) | 0.40~0.78 | 22~36 | 22~34 | 들쭉날쭉 |
| 창고 고철 | 0.32~0.48 | 18~28 | 42~54 | 공방에 언제나 있음 (재시도 보장) |

- 원료 값은 **채집 순간** 범위 안에서 정하고 **출처(장소·일차)**를 남겨 결과 화면까지 보여 준다 (GDD 6장).
- 감정 표시: 일반 화면은 낮음/보통/높음(탄소는 매우 높음까지), F2로 실제 수치.
- **제철 = 원료 1 + 숯 1 → 강괴.** 좋은 숯(숲)이 있으면 자동으로 먼저 쓰고 탄소 +0.05·불순도 −4, 없으면 마을 숯으로 불순도 +5. 채집·제철을 짧은 결과 처리로 연결한다는 GDD 6장 제안.
- 재료 두 개를 골라 "제철하고 단련 시작". 시작하면 원료는 소모되고 v0.1에서는 중간에 그만둘 수 없다.

### 3.2 가열·접쇠(단련) — `core/forge/refine.js`
GDD 7.2 제안대로 **공방 안에서만 흐르는 짧은 실시간 구간**. 버튼: 숯 넣기 / 풀무질 / 꺼내서 모루에 올리기·화덕에 다시 넣기 / 산화물 털기 / 늘이고 접기 / 단련 마치기.

- 화덕 목표 온도 = 520 + 숯×6 + 바람×4.6 (숯 0~100은 서서히 타 없어지고, 풀무 바람은 초당 20씩 빠진다). 화덕은 목표를, 강재는 화덕을 천천히 따라간다. 모루 위에서는 식는다.
- **침탄**: 화덕 안 950~1250°C, 숯 50 이상일 때 초당 +0.004%. **숯을 넣는 즉시 탄소가 오르지 않는다** (GDD 7.2).
- **과열** 1280°C↑: 탈탄(초당 −0.02%), 산화물이 빠르게 쌓임. **백열** 1380°C↑: 불순도↑·균일도↓("쇠가 탄다").
- **접기 1회**: 균일도 +(100−U)×0.30×효율, 불순도 −I×0.22×효율 + 남은 산화물×6, 탄소 −0.03%(1250°C↑이면 −0.05%), 온도 −110°C.
  - 효율 = 0.85^(접은 횟수) × (1 − 산화물×0.6) × (900°C 미만이면 0.7) → **반복할수록 개선 폭이 줄고**, 산화물을 털지 않으면 효과가 떨어지고 때가 섞인다. 800°C 미만에서는 접을 수 없다. 최대 10회, 최소 1회.
  - 화면에 "다음 접기 효과: 큼/보통/작음"을 보여 줘 종료 판단을 돕는다.
- 화덕용 숯은 **추상화**(인벤토리 숯을 쓰지 않음). 인벤토리 숯은 제철에만 쓴다 — 가열 중 숯이 떨어져 막히는 일을 피하려고.
- 온도는 항상 **색 + 문구**(식은 쇠 / 검붉은 빛 / 어두운 적색 / 진홍 / 주홍 / 주황 / 노란 주황 / 노란빛 / 과열·연노랑 / 백열·타는 중)로 보여 준다. 강재 그림의 색과 빛 번짐도 같은 표를 따른다 (GDD 10장).
- 두 번째 강재는 첫 강재가 남긴 화덕 상태(숯·온도)를 이어 쓴다.

### 3.3 배정·접합
- 단련을 마친 두 강재를 나란히 보여 주고 **피철(날·바깥층)**을 고른다. 나머지가 **심철(속심)**.
- 두 강재의 세 변수는 **평균내지 않고 따로 유지** (GDD 7.3).
- 츠쿠리코미는 피철이 심철을 감싸는 **고정 구조 하나로 자동 처리**(망치 연출만).

### 3.4 성형 — `core/forge/shaping.js`
- 도신을 **6구간**(칼끝·앞날·앞 중간·뒤 중간·밑날·밑동)으로 나누고, 구간 버튼이나 **도신 그림을 직접 클릭**해 두드린다.
- 800°C↑ +14, 650~800°C +8, 650°C 미만 +4이며 **냉간 타격**으로 기록(잔금 → 결과의 균열 위험). 이웃 구간도 +2. 122를 넘기면 **과타격**(얇아짐).
- 초당 26°C 식는다. "다시 달구기"는 1.2초 연출 뒤 1050°C.
- 모든 구간이 70 이상이면 마칠 수 있다. 형상 품질 = 구간 평균(100 상한) − 편차×0.6 − 과타격 구간×6.
- 두드릴수록 도신 그림이 두꺼운 막대에서 얇고 휜 칼 모양으로 바뀐다.
- 성형 이후 강재 세 변수는 바뀌지 않는다. 형상 품질·결함만 따로 기록 (GDD 7.3). 길이·무게·곡률 설계는 없음.

### 3.5 다듬기·점토 *(미결 "점토 도포 방식")*
- **기본 패턴 하나**(등 쪽 두껍게, 날 쪽 얇게)를 버튼 하나로 바른다. 계산에 영향을 주는 선택지는 아직 없다.

### 3.6 담금질 — `core/forge/quench.js`
- 긴 숯불 위에서 420°C부터 1010°C를 향해 서서히 달궈진다. 650°C 이상에서 **고르게 달궈짐**이 올라간다(초당 +7%).
- "숯불에서 잠시 들어 올려 식히기 / 다시 올리기"로 온도를 붙잡을 수 있지만, 공기 중에서는 고름이 조금씩 무너진다.
- **적정 760~840°C**는 화면에 숫자로 표시하지 않는다(F2 개발 수치에서만). 빛깔 문구와 소문, 결과 화면의 원인 설명으로 배운다 — "결과를 보고 다음엔 다르게"라는 GDD 1장의 감각을 위해.
- "물에 담그기!" → 긴 물통에 넣는 연출(증기·물보라·흔들림) → 결과 계산.

### 3.7 결과 — `core/forge/result.js`
결과는 **피철·심철의 세 변수, 성형, 담금질 시점의 누적**이다. 무작위 성공/실패가 아니다.

| 축 | 계산 | 표시 |
|---|---|---|
| 경화 | 피철 탄소(0.3%→0.7%에서 0→1) × 담금질 온도 계수(700°C 미만 0.15, 760~840°C 1.0, 더 뜨거우면 서서히 감소) × 피철 균일도 계수(0.6+0.4×U/100) | 충분한 경화 / 부분 경화 / 경화 부족, + 국소 불균일(피철 균일도 65 미만 또는 고름 55% 미만) |
| 건전성 | 균열 위험 = 피철 탄소 0.85% 초과분 + 담금질 840°C 초과분 + 피철·심철 불순도 + 피철 균일도 70 미만분 + 냉간 타격 + 심철 탄소 0.35% 초과분. 휨 위험 = 고름 부족 + 성형 편차 + 피철·심철 탄소 차가 작음 + 심철 균일도 50 미만분 | 파단(1.25↑) / 균열(0.8↑) / 휨(0.62↑) / 정상 |
| 형상 | 성형 품질과 결함(과타격 구간, 편차, 냉간 타격) | 고른 / 보통 / 거친 형상 |
| 피드백 | 위 계산에 실제로 들어간 항목만 영향 크기 순 6개 | +/− 표시와 수치가 들어간 문장 |

- **균일도가 낮은 재료만** 결과가 최대 ±0.12 흔들린다(시드 난수). 흔들림이 컸다면 원인 목록에 "재료 균일도가 낮아 결과가 흔들렸다"가 나온다.
- 종합 점수 = 경화 35 + 건전성 40(같은 '정상'이어도 균열·휨 위험이 높았으면 감점) + 형상 25 → 명도의 기미(90↑) / 쓸 만한 도신(70↑) / 아쉬운 도신(50↑) / 실패작, 파단은 부러진 도신.
- 조합별 확인(같은 성형·담금질 기준): 사철 피철+철광석 심철·4번 접기 ≈ 93점(명도의 기미), 1번만 접기 ≈ 83, 8번 접기(탄소를 너무 잃음) ≈ 84, 산화물을 안 털고 접기 ≈ 87, 사철+고철 ≈ 85, 고철+고철 ≈ 30(균열), 피철·심철을 거꾸로 ≈ 28, 담금질 920°C ≈ 55(균열), 720°C ≈ 71(경화 부족).
- 결과 화면은 완성 도신 그림(하몬·균열·부러짐·휨 반영), 재료 출처, 지난 도신과의 점수·주요 변수 비교를 보여 준다.
- **제작 1회 = 달력 2일 고정** *(미결 "제작의 달력 소모")*. 결과가 나올 때 한꺼번에 더한다.

### 3.8 재시도
- 결과에서 "다시 제작하기"(공방 재료 고르기로) 또는 "재료를 구하러"(지도로).
- 창고 고철이 항상 있어 재료가 없어도 다시 만들 수 있다 → 재시도가 영구히 막히지 않는다.

## 5. 검증 방법과 결과

- `npm test` — 규칙 테스트 12개 (Node, 브라우저 없이): 비인접 출발 불가, 출발=첫날+사건 1회, 대응 전 행동 잠금, 노숙(위치 유지·하루·식량·피로), 되돌아가기(실제 일수·귀환 버튼 이름·출발점에서 멈춤), 도착일 사건 중복 없음, 탈진 후 재개, 채집 원료의 출처가 공방까지, 고철만으로 제작 완주, 접기의 체감·산화물 영향, 재료·조작 차이가 결과에 드러남.
